# Help — documentatie voor de klant

Nederlandstalige uitleg voor eindgebruikers: planners en medewerkers van een klant. **De enige
map in `docs/` die niet voor ons is.**

Op dit moment leeg, en dat is bewust: er is nog geen klant
([my-company.md](../../my-company.md): fase is bouwen). Hulpteksten schrijven voor nul
gebruikers is precies het soort werk dat uren kost en niets oplevert.

## Als de eerste klant er is

Wat er dan nodig is, ongeveer in deze volgorde — geleid door wat iemand op dag één tegenkomt:

1. **Aan de slag** — account maken, organisatie aanmaken, collega's uitnodigen
2. **Een weekplanning maken** — dienst aanmaken, verslepen, bevestigen, dupliceren
3. **Open diensten** — wat een gestreepte dienst is en hoe je hem vult
4. **Beschikbaarheid en afwezigheid** — wat een medewerker zelf doet en wat de planner doet
5. **Rollen en rechten** — wie mag wat, in gewone taal
6. **Je planning delen** — zodra [besluit 0003](../decisions/0003-sharing-a-planning-frontend-only.md) gebouwd is

## Regels voor deze map

- **Nederlands.** Alles hierbuiten is Engels waar het over code gaat; hier niet.
- **Geen jargon.** Geen "tenant", geen "module policy", geen "record". De lezer plant mensen
  in, hij bouwt geen software.
- **Schrijf wat het scherm doet, niet wat de code doet.** Een schermafbeelding veroudert;
  beschrijf de stap zo dat hij ook klopt na een kleine UI-wijziging.
- **Eén taak per bestand**, met een titel die de vraag van de lezer is ("Hoe nodig ik een
  collega uit?"), niet de naam van een feature.
